How it works

A mascot that walks the page instead of waiting in the corner

Most page help sits still in the bottom right until someone clicks it. This one arrives on its own: a 16 × 30 pixel robot chews up the headline, climbs out from behind the hero card, and then reappears beside whatever section the reader has scrolled to, with one remark about that section. It is a landing page tour with a character attached, and its bubble takes typed questions.

Try it

  1. Wait two seconds on the hero. The headline breaks into block glyphs, pixel crumbs fall, and the robot climbs up from behind the experiment card.
  2. Scroll. It drops in at step 3, climbs the positioning map, leans on the free plan, and walks in from the left in the footer — once each.
  3. Ask a question in its bubble, such as How does Skene work? or What would I measure for a signup experiment?. Stand's AI Stand-in or an available person answers in the same bubble.
  4. Click the robot to hide or show the bubble. summon TEEMU.EXE in the footer brings it back; replay the intro runs the whole tour again.
  5. Turn on Reduce motion in your OS: the glitching, crumbs and walking stop, and the robot simply appears where it was heading.

The sprite

The robot is a string array, one character per pixel, painted into a 16 × 30 canvas that CSS scales up with image-rendering: pixelated. Swapping single rows gives the blink, the talking mouth and the walk cycle, so the whole character is a few hundred bytes with no image files.

const PAL = { L:'#2fd1b4', M:'#9aa0a8', H:'#3b2a1f', S:'#e9bfa2', B:'#b85c2e' /* … */ };
const BASE = [
  ".......LL.......",   // antenna light, blinks between two teals
  "....HHHHHHHH....",   // hair
  "..SGWEGSSGWEGS..",   // glasses
  "..BBBBWWWWBBBB..",   // beard and mouth
  /* … 30 rows in all */
];

function draw() {
  const rows = BASE.slice();
  if (blink) rows[9] = "..SGGGGSSGGGGS..";          // eyes closed
  if (talk && tick % 2) rows[15] = "..BBBBbbbbBBBB.."; // mouth open
  rows.forEach((r, y) => { for (let x = 0; x < 16; x++) {
    const c = r[x]; if (c === '.') continue;
    ctx.fillStyle = PAL[c]; ctx.fillRect(x, y, 1, 1);
  }});
}

One stop per section

Each stop names the element to stand on, how to arrive, where to sit relative to that element's box, and what to say. An IntersectionObserver fires a stop the first time its section is 35% visible, and the positions are recomputed on resize, so the robot stays glued to the layout.

const SPOTS = {
  hero: { el: '#verdict', head: '#h1', enter: 'climb',
          pos: r => [r.x + r.w - W - 28, r.y - H + 10],
          lines: ["...not a virus.", "ok, i did eat your headline for a second. it is back."] },
  how:  { el: '#steps .step:nth-child(3)', head: '#h2how', enter: 'drop', /* … */ },
};

const io = new IntersectionObserver(entries => {
  for (const e of entries) {
    if (!e.isIntersecting || seen.has(e.target.dataset.spot)) continue;
    seen.add(e.target.dataset.spot);
    appear(e.target.dataset.spot);          // climb, drop or walk in
  }
}, { threshold: .35 });

The conversation is Stand Chat

The short lines spoken while the mascot tours the page are local presentation. Typed questions start a real Stand conversation. stand-visitor.js discovers a responder, creates a session on the first message, sends over HTTP, receives replies over a WebSocket, and restores the conversation after a reload. The bubble also handles handoffs, connection recovery, email follow-up offers, notices, and Stand attribution.

The shared demo site ID works on any domain including localhost and preview deployments. Replace it with your Site ID to have your own Stand-ins and team answer. This example uses the Visitor API directly, so it does not load stand.js or show its floating button.

import { StandVisitorClient } from './stand-visitor.js';
const client = new StandVisitorClient({ site: 'demo', scope: 'glitch-mascot' });
client.subscribe(renderChat);
client.mount();
// The visitor's first typed question starts the Stand session.
await client.send(question, { prompt, analyticsId: 'glitch-mascot' });
