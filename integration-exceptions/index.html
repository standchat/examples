Try the exception
  1. Choose a source, destination, and trigger/action with the menus. Run the paid sample.
  2. Add Paid customers only, choose the trial record, and run again. It stops at step 02.
  3. Change the failure branch to Send to team review. Run again to follow the other path.
  4. Attach the current workflow, review its context, and explicitly send your question. A real Stand conversation opens inline.
Copy the whole folder
npx degit standchat/examples/integration-exceptions my-flowspoke
Serve the folder over HTTP with any static server. No install or build step is needed. All application code is local; /_shared/ only supplies the gallery bar and can be removed.
Context, with consent
import { StandVisitorClient } from './stand-visitor.js';

const client = new StandVisitorClient({
  site: 'demo', scope: 'flowspoke-exception'
});
client.mount(); // discovery, not a new conversation

// Only inside the visitor's submit handler:
await client.send(question, {
  owner: 'exception-step',
  prompt: contextFor(attachedWorkflow)
});
The first snapshot uses Stand’s supported session prompt (under 2,000 characters). Updated snapshots are sent as visible visitor text with the next question. Replies are text, never canvas commands.
Make it yours
Replace the Stand script with your installation snippet from Sites. The local client reads that script’s Site ID. Configure your responders and registered domain. The demo site uses Stand’s shared AI and does not put conversations in your account.
The local client preserves notices, attribution, handoffs, offered email follow-ups, pending-message IDs, and same-tab reload recovery. Storage denial falls back to memory. See the custom chat UI contract ↗.
