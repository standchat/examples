Add Halloween
to your website.

Copy this code and paste it before </body> on your page. It loads the characters, their assets, and Stand Chat automatically.

No download. No separate chat snippet.

PASTE BEFORE </BODY>
<script defer
  src="https://cdn.jsdelivr.net/gh/standchat/examples@c0472d6173d90c487822ccb263659ffc94a70780/halloween/halloween.js"
  data-stand-id="demo"
  data-rating="pg"
  data-season="always">
</script>

Works right away with demo chat. Your chosen characters and settings are included.

Connect your own chat

In Stand → Sites → your site → Installation snippet, copy the data-stand-id value and replace demo above.

Already have Stand on this page? Halloween mode uses your existing installation.

Source files & self-hosting Optional ↗

The copied code handles installation. If you prefer to host the files yourself, download the source package and follow its INSTALL.txt. Keep halloween.js beside assets/, then change only the copied script’s src to your uploaded file.

For more control, configure it in JavaScript:

window.StandHalloween.configure({
  rating: 'pg-13',
  greeting: 'A little lost? I know my way around.',
  idleDelay: 15000,
  activity: 'calm',
  placement: 'auto',
  season: '10-01/11-01'
});

StandHalloween.parade();  // Preview your selected cast
StandHalloween.pause();   // Freeze motion
StandHalloween.stop();    // Clear the page
StandHalloween.start();   // Let them roam again
StandHalloween.summon();  // Invite the ghost now
StandHalloween.destroy(); // Remove everything

Set window.StandHalloweenConfig before the script loads to supply the same options at startup. See the full configuration reference.

Give the spirits a place to land Page placement ↗

Explore the page finds suitable cards and headings automatically. Chosen spots uses only elements you mark. Edges only keeps characters at the window edges.

<article data-halloween="perch peek">…</article>
<div data-halloween="hang">…</div>
<section data-halloween="none">Keep this area clear.</section>

Mark a card with peek for a ghost or pumpkin, hang for a bat, or perch for a suitable landing spot. Add none to areas such as checkout, pricing controls, and navigation. If there is no suitable space, a character waits for another visit.

Characters use a separate layer. Your markup, layout, and click handlers stay intact. Use StandHalloween.destroy() to remove the layer when your page unmounts.

Good house guests Behavior & accessibility ↗

The animation layer leaves the page clickable. Characters pause when hovered or focused, work with a keyboard, and respect reduced motion. No sound, flashing lights, or automatic chat opening.

Escape dismisses the current visitors. On your site, a small pause control freezes motion. This demo also has a separate off switch that removes the visitors. Characters stop appearing while the tab is hidden or the visitor is typing in a form. The idle greeting is limited to once per session by default.

Chat still depends on your Stand setup and availability. If Stand is unavailable, the character explains that and offers another try. Halloween mode adds no separate tracking or cookies; its chat handoff identifies the character through Stand’s normal integration.
